Odin Recipes: Lasagna
This project is part of The Odin Project curriculum, built to practice foundational HTML skills by creating a simple recipe webpage.

📋 About
A basic web page featuring a recipe layout complete with a title, descriptive text, ingredients, and step-by-step instructions.

🛠️ Built With
HTML5

🚀 Features
Recipe Title & Images: Showcases the main dish with accompanying image previews.

Description Section: Brief overview of the dish.

Ingredients List: Bulleted breakdown of required items.

Step-by-Step Instructions: Numbered list guiding through the preparation process.
